# Как помочь проекту

- **Нашли ложное срабатывание?** Откройте issue «Ошибка проверки»: адрес страницы, код находки (например `law.consent`) и что на самом деле на странице.
- **Новая технология.** Добавьте сигнатуру в `src/analyzers/tech.ts`: имя, категория, признаки (`hosts`, `html`, `globals`), флаг `foreign` для зарубежных сервисов.
- **Новая проверка.** Добавьте её в нужный файл `src/analyzers/*.ts` с уникальным `id`, подсказку «как исправить» — в `HINTS` (`src/report/insights.ts`), тест — в `test/`, тестовую страницу — в `test/fixtures/`.
- **Промпты экспертов** лежат в `prompts/`. После изменения выполните `node scripts/build-plugin.mjs`.

Перед pull request: `npm run typecheck && npm test`.
